# S3·H6 교체안 (제안, 아직 적용하지 않음)

근거: 사람 독립 라벨링 라운드 5(90.0%)에서 S3와 H6 복약이 합의되지 않았다(`docs/decisions.md` 2026-10-26). 초안 스펙은 `data/golden/drafts/S3_H6_replacement.draft.json`(스키마 검증 통과, `data/golden/specs/`에는 반영하지 않음).

## 1. 왜 나쁜 케이스인가
| 케이스 | 문제 | 사람이 읽은 값 | 정답 |
|---|---|---|---|
| S3 | "점심 **약은** 반 정도 드셨어요"는 양→약 동음 오인식이다. 글만 보면 "약을 반 정도 드셨다"도 자연스러워 복원이 합의되지 않는다. 정답은 참고 발화 기준 식사 절반, 복약 missing | 복약 복용, 특이사항 "약은 반 정도 드셨어요", 식사 비움 | 식사 절반, 복약 missing |
| H6 복약 | "약은 따님이 아침저녁으로 챙겨드린다고 하시더라고요"가 오늘 복약 확인인지 평소 관행 전언인지 정책에 없다 | 복용 | missing + needs_confirm |

## 2. 교체안
스펙 id(S3, H6)와 분할(test)을 그대로 두고 **내용만 교체**한다. 다른 39건의 id(`gs-021`~`gs-060`)와 diversity 배정이 변하지 않게 하기 위해서다.

| | 기존 | 교체안 |
|---|---|---|
| S3 | 동음 오인식(양→약), "부분 복원" | **연음 표기 오인식** 세 군데(`넘어진 일은`→`너머진 이른`, `반 정도 드셨어요`→`반 정도 드셔써요`, `약도 드셨어요`→`약또 드셔써요`). 복원 방법이 하나뿐이라 누가 읽어도 같은 값. 정답 식사 절반, 복약 복용, 낙상 없음, 세 필드 모두 `recoverable=true`. S1(띄어쓰기)과 다른 유형의 복원 가능 오류 |
| H6 | 전언으로 혈압 정상 + 전언으로 약 챙김 + 본인 측정 불가 | 전언은 **혈압뿐**, 본인 측정 불가(혈압계 미지참), 식사 서너 숟가락(소량), **약과 낙상은 언급하지 않음** → 복약·낙상·맥박·혈압 missing + needs_confirm, 특이사항은 측정 미실시. 해석 여지 제거 |

S 프로브가 3건(spacing, negation_drop, liaison)으로 유지된다. 대신 **"부분 복원" 유형은 사라진다**. 이 유형은 사람도 합의하지 못해 정답을 세울 수 없다는 것이 이번 결과다. 필요하면 별도 비-F2 진단용으로 나중에 따로 만든다.

## 3. 정책 공백(교체와 별개로 필요)
"평소 관행·제3자가 챙긴다는 전언"을 오늘 복약으로 볼지 정하지 않았다. 교체안 H6는 이 문제를 **피하는** 설계이고 해결하지 않는다. 제안(#14, 사용자 결정 필요): *오늘 복약을 화자가 직접 보거나 직접 들은 경우만 기록한다. 평소 관행이나 제3자의 일반적 전언("챙겨드린다고 하시더라")은 사실이 아니므로 missing + needs_confirm.* 현재 H6 정답과 같은 방향이다.

## 4. 적용 절차 (승인 후)
1. 기존 S3·H6 스펙과 후보를 `data/golden/retired/`로 옮기고 사유를 남긴다(삭제 안 함).
2. 초안을 `data/golden/specs/probe_S.json`, `probe_H.json`에 반영, `--spec S3 --spec H6`로 생성(Opus 5.5, 다른 케이스 캐시 불변).
3. 자동 점검 A~T 통과 확인, `--promote`로 `v2_test.jsonl` 재생성(id 불변, 두 줄만 변경).
4. 테스트와 문서 갱신(`test_specs` 의 H6 특이사항 단언 등), 결정 로그에 교체 사유와 영향 기록.
5. **영향**: 과거 블라인드 비교(`v2-blind2/4/5`)는 옛 S3·H6 기준으로만 재현된다(`retired/` 필요). dev 실측과 test 미실행 상태에는 영향 없음(S3·H6는 test).

## 6. 솔직한 한계: 교체만으로 F2 95%는 어렵다
- 라운드 4·5에서 사람이 본 20건 중 교체 대상 2건을 빼면 18건 144필드이고, 그중 불일치가 **8건**이다(라운드 4의 5건 + 라운드 5의 V3 방문 시각 실수, N3 식사 누락, N3 특이사항 3건). 일치율 136/144 = **94.4%**. 이 8건은 교체와 무관하다(라벨러 실수, 정책 미적용).
- 교체한 2건과 남은 후보(I3, V2 등)를 새로 라벨해 합산해도, 176필드 기준 95%는 168 일치 → 불일치 8건 이하여야 하므로 **새 라벨에서 한 건도 틀리면 안 된다**.
- 또 교체 사유가 "사람이 합의하지 못함"이므로 결과를 본 뒤 케이스를 고르는 **선택 편향**이 있다. 새 케이스의 라벨 결과는 좋든 나쁘든 모두 합산해야 한다.
- S2(부정어 탈락)는 정답이 참고 발화 기준이라 글만 보는 사람의 라벨은 설계상 정답과 다르다. F2 표본에서는 `recoverable=false` 필드를 비교 대상에서 빼야 공정하다.
