## 일정 대비
- 계획상 2주차(~11/5) 목표는 **얇은 E2E 데모 v0**(텍스트/음성 → Extractor + evidence → 검토 화면)이고, 아직 시작 전이다.
- 3주차 게이트: 11/12까지 데모 v1이 안 돌면 Re-listener 범위를 줄인다. 기능 동결 12/3.
- 평가 쪽은 목표(골든 60건, ablation)를 이미 넘었다. 지금 병목은 **A의 Verifier·Re-listener와 데모**다.

## 제안 순서
1. E2E v0: `POST /drafts`(transcript → FlaggingExtractor 필드 + evidence + flag) + 인메모리 저장, 검토 화면은 시안 HTML 재사용. DB·STT는 보류.
2. Verifier(타 모델 계열) → ablation 표 행 추가(단일 → +Verifier).
3. LangGraph 오케스트레이션(병렬 팬아웃, HITL interrupt) 후 Re-listener는 텍스트 재검증 폴백 어댑터부터.
4. 사람 확인 표본·식사 규칙 v3는 데모 사이 빈 시간에.
