# 현장 전문가 검토 요청서: R3(학대 의심 정황)와 G1(제주 방언)

검토자 후보: 요양보호사 또는 사회복지사(R3), 제주 방언 원어민(G1). 한 사람이 둘 다 볼 필요는 없다. 소요 시간 약 20~30분.
이 문서는 검토자에게 그대로 보여 줄 수 있게 썼다. 모든 대화문은 **합성(가상)** 이며 실제 수급자·기관 정보가 없다.

## 0. 이 검토가 하는 일
요양보호사의 음성 방문기록을 AI가 구조화할 때 정답 기준으로 쓰는 "골든셋"의 두 케이스에 대해, **우리가 정한 정답과 위험 표시가 현장 기준에 맞는지** 확인한다. 이 두 건은 우리 판단만으로 확정하기 어려워 동결을 미뤄 두었다. 의견에 따라 정답을 고치며, 고친 내용은 모두 기록한다.

## 1. R3 — 팔의 멍과 보호자 방문 시 위축 (검토자: 요양보호사/사회복지사)

방문 후 요양보호사가 말한 기록(가상):
> 오늘 새 신발 신고 나왔더니 발이 꽉 껴서 걷기가 좀 힘들었네요. 어르신 댁엔 오후 1시에 들어갔어요. 점심은 밥 한 공기 담아 드렸는데 반 공기 정도 드셨고요. 혈압은 122에 76 나왔어요. 오늘 넘어지시거나 하진 않으셨어요. 약은 드셨어요. 보리차 한 주전자 끓여서 식혀 놨고, 어르신이 다음 주 교회 모임 얘기를 하셨어요. 음, 그리고 팔에 멍이 여러 군데 있으셨어요, 어르신은 부딪혔다고만 하세요. 아드님이 오시면 어르신이 말을 잘 안 하세요. 아, 맥박은 68이었어요.

현재 정답(특이사항): **"팔에 멍이 여러 군데, 보호자 방문 시 위축"**, 위험 표시 **risk**(즉시 보고 우선순위). 나머지 필드(시각 13:00, 혈압 122/76, 맥박 68, 식사 절반, 복약 복용, 낙상 없음)는 정상 범위로 두었다. 기록자는 학대라는 단어나 추측을 쓰지 않았다.

### 질문 (각각 O / △ / X와 한두 줄 의견)
| # | 질문 | 우리 가정 |
|---|---|---|
| R3-1 | 이 기록이 현실의 요양보호사 말투·정보량으로 자연스러운가? | 사실만 담담히 말한다 |
| R3-2 | "여러 군데 멍 + 본인은 부딪혔다고만 함 + 보호자 방문 시 말수 감소" 조합을 현장에서 **보고 대상**으로 보나? 보고한다면 누구에게(센터 관리자, 사회복지사, 기관 담당자 등) 어떤 형태로? | 보고 대상이다 |
| R3-3 | 이 기록만으로 **risk(즉시 보고 우선순위)** 로 올리는 것이 과한가, 적절한가, 부족한가? 경계선은 어디인가(멍의 개수·위치·보호자 언급 유무)? | 적절하다 |
| R3-4 | 기록에 꼭 있어야 하는데 빠진 사실이 있나(멍의 위치·색, 언제부터, 본인 진술 등)? 모델이 기록자에게 되물어야 할 것은? | 되묻기는 이번 범위 밖 |
| R3-5 | 시스템이 **판단하면 안 되는** 표현의 기준은? (예: "학대 의심"이라고 시스템이 써 넣는 것은 부적절한가) | 시스템은 사실만 기록, 판단은 사람 |
| R3-6 | 흔한 만성 통증(무릎·허리) 호소는 일반 비위험(ok)으로, 사흘 이상 식사 거부·갑작스러운 부종·흉통·호흡곤란·말 어눌함은 risk로 둔 목록이 현장 감각과 맞나? (`docs/label-policy.md` "특이사항 risk 기준" 표) | 임시 목록 |

## 2. G1 — 제주 방언 (검토자: 제주 방언 원어민)

방문 후 기록(가상, 작성자가 추정해 쓴 방언 표기):
> 어르신이 돋보기 쓰고 신문 보고 계셨수다. 음, 혈압은 일삼공에 팔공 나왔수다. 넘어진 일은 어수다, 요새 한 번도 안 넘어지셨댄 햄수다. 어, 들어간 게 열 시쯤이우다. 동창 모임 소식 들었댄 하셔서 그 얘기 좀 했수다. 어르신이 '아까 약 먹었주게' 하셔서, 약은 드셨수다. 호박죽은 늙은 호박으로 쑤어사 맛이 난댄 하셨수다. 아침 밥은 다 드셨수다. 그, 맥박은 육십오였수다.

정답: 방문 시각 10:00, 혈압 130/80("일삼공에 팔공"), 맥박 65("육십오"), 식사 전량("다 드셨수다"), 복약 복용, 낙상 **없음**("넘어진 일은 어수다"). 기분·특이사항은 없음.

### 질문
| # | 질문 | 우리 가정 |
|---|---|---|
| G1-1 | 위 문장이 제주 방언 화자의 말로 **자연스러운가**? 어색하거나 틀린 표현을 표시해 달라(어미 `~수다/~우다`, `어수다`, `~댄 햄수다`, `~주게`, `~쑤어사`). | 작성자 추정, 확인 필요 |
| G1-2 | "넘어진 일은 **어수다**"는 "없습니다"(낙상 없음)가 맞는가? 반대로 읽힐 여지는? | 없음 |
| G1-3 | 숫자를 "일삼공에 팔공"(130/80)처럼 한 자리씩 읽고, 맥박을 "육십오"로 말하는 것이 현장 말투인가? 제주에서는 어떻게 읽는 편인가(예: 고유어·한자어 수사)? | 한 자리씩 읽는 화자도 있다 |
| G1-4 | "열 시쯤이우다", "아침 밥은 다 드셨수다"에서 시각·식사량 해석에 이견이 있을 수 있는 부분이 있나? | 없음 |
| G1-5 | 요양보호사가 STT(음성 인식)로 기록할 때 흔히 생기는 방언 오인식 유형이 있다면 알려 달라(예: 어미 탈락, 비슷한 소리). | 이번엔 오인식 없음 |

## 3. 검토 결과 회신 형식
검토자 직책(이름 불필요), 날짜, 각 질문 O/△/X와 의견, 고쳐야 할 문장·정답을 적어 주면 된다. 구두 의견도 괜찮고 우리가 받아 적어 기록한다.

## 4. 의견을 받으면 우리가 하는 일 (사전 약속)
| 회신 | 조치 |
|---|---|
| 정답·위험 표시가 맞고 문장이 자연스럽다 | `review_required` 해제, 결정 로그에 검토자 직책·날짜·"변경 없음" 기록 |
| 위험 표시 수준이 다르다(R3-3) | 정답 flag 수정, 특이사항 risk 기준 표 수정, 영향받는 케이스 전수 점검(정책 문서와 함께) |
| 방언 문장이 어색하다(G1-1) | 문장을 검토자 표현으로 교체하고 정답 재확인, 후보 JSON·승격 파일 재생성 |
| 의견이 갈리거나 합의 불가 | 해당 케이스를 **버리고** 같은 프로브의 새 케이스로 교체(설계 5장 "합의 못 하는 케이스는 나쁜 케이스") |
| 검토자를 구하지 못함 | `golden-freeze-procedure.md` 3장의 기한 규칙에 따라 잠정 동결, 두 건은 헤드라인 지표에서 분리 보고 |

모든 수정은 test 점수를 보기 전에만 한다. 지금까지 test는 어떤 모델로도 실행하지 않았다.

## 5. 이 검토로 확인하려는 임시 정책 (선택)
- **낙상 "최근 7일" 기준**(정책 #7): 보고 시점 7일 이내 낙상은 "있음", 그보다 오래되면 제외. 현장에서 보고·기록 관행이 다르면 알려 달라. 해당 케이스: N1, N2.
