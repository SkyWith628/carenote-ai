# 케어노트 AI 발표 덱 (HTML, 22장)

PDF 발표자료(`6조_케어노트AI`, 22장)와 **내용이 1:1로 같은** 브라우저용 프레젠테이션입니다.
발표는 **크롬 브라우저**에서 `../케어노트AI_발표덱_standalone.html` 한 파일만 열면 됩니다(인터넷 불필요).

## 발표 방법

1. `케어노트AI_발표덱_standalone.html` 을 크롬으로 연다 (더블클릭).
2. `F` 를 눌러 전체 화면으로 전환한다. 발표 중 마우스가 멈추면 아래 조작 막대는 자동으로 숨는다.
3. `→` / `Space` 로 넘기고, `←` 로 돌아간다.

| 키 | 동작 |
|---|---|
| `→` `Space` `Enter` `PageDown` | 다음 장 |
| `←` `Backspace` `PageUp` | 이전 장 |
| `1`~`9` | 해당 목차 장으로 이동 (목차 슬라이드의 항목 클릭도 가능) |
| `F` | 전체 화면 켜기/끄기 |
| `N` | 발표 노트(대본) 패널 열기/닫기 |
| `G` 또는 `O` | 슬라이드 목록 열기 (`Esc` 닫기) |
| `T` | 발표 타이머 초기화 (첫 장을 넘기는 순간 자동 시작, 13분부터 흰색 경고) |
| `Home` / `End` | 첫 장 / 마지막 장 |

터치 화면에서는 좌우 스와이프, 마우스는 화면 왼쪽 22% 클릭 = 이전, 나머지 클릭 = 다음입니다.
주소 뒤에 `#s7` 처럼 붙이면 해당 장에서 바로 시작합니다.

## 파일 구성

```
케어노트AI_발표덱/
├─ index.html         # 덱 본체 (슬라이드 22장 + 엔진). 폴더 버전은 images/, fonts/ 를 참조
├─ images/            # 일러스트·화면 캡처 (webp). PDF 를 4000px 로 렌더해 잘라낸 고해상도·투명 배경본
├─ fonts/             # 덱에 쓰인 글자만 담은 서브셋 글꼴 (Gothic A1 5종 + IBM Plex Mono, 총 ≈ 210 KB, OFL)
├─ tools/build.py     # 서브셋 글꼴 생성 + 단일 파일(standalone) 빌드
└─ tools/crop_illus.py # (참고) 발표 PDF 렌더(pdftoppm, 4000px)에서 일러스트를 잘라 투명 배경 webp 로 만든 스크립트
../케어노트AI_발표덱_standalone.html   # 이미지·글꼴을 모두 내장한 단일 파일 (≈ 1.4 MB) ← 발표용
```

내용을 고치려면 `index.html` 을 수정한 뒤 아래를 실행해 standalone 을 다시 만듭니다.

```bash
pip install fonttools brotli          # 최초 1회
python3 tools/build.py                # 글꼴 원본이 없으면 Google Fonts 저장소에서 자동 다운로드
```

## 설계 메모 (왜 이렇게 만들었나)

- **고정 좌표계 + 비율 스케일**: 모든 슬라이드는 1600×900 무대 위에 절대 좌표로 배치하고, 창 크기에 맞춰 `transform: scale` 로만 줄입니다.
  해상도(16:9, 16:10, 4:3)나 브라우저 확대율이 달라도 슬라이드 안의 배치가 절대 바뀌지 않습니다.
- **글꼴 내장**: Google Fonts 를 실시간으로 불러오던 방식은 발표장 네트워크가 없으면 대체 글꼴로 바뀌어 줄바꿈·겹침이 생깁니다.
  덱에 실제로 쓰인 618자만 서브셋해 woff2 로 내장했으므로 오프라인에서도 같은 모양입니다.
- **투명 배경 일러스트**: 원본 덱은 PDF 에서 저해상도로 잘라낸 흰 배경 이미지를 `mix-blend-mode: multiply` 로 겹쳐 썼는데, 그러면 색 있는 배경(말풍선) 위에서 인물이 파랗게 물들고 잘려 나온 점선 조각까지 함께 보입니다.
  PDF 를 4000px 로 다시 렌더해 배경·점선·장식을 제거한 투명 webp 로 교체했습니다(2배 해상도).
- **넘치지 않는 상자**: 글이 들어가는 상자는 `height` 대신 `min-height` 와 flex 를 써서, 글이 길어지면 상자가 늘어나지 보이지 않게 잘리거나 겹치지 않습니다.
- **동작 감소 설정 존중**: OS 의 "동작 줄이기" 가 켜져 있으면 모든 등장 애니메이션을 끄고 최종 상태를 바로 보여줍니다.
