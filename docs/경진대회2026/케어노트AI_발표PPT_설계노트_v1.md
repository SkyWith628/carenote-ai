## 3. 슬라이드 상세

### 3.1 슬라이드 2-① — 수요 폭증 (초안 확정)

**헤드라인:** "20년 뒤, 3명 중 1명이 노인 — 돌봄 수요가 폭증합니다."

**구성**
- 좌: 도넛 2개. 2025년(노인 20.3%, 1,051만 명, 세계 22위) → 2045년 예상(37.0%, 약 1,780만, 세계 1위 전망)
- 우: 막대. 장기요양 인정자 116.5만(2024) → 312.6만(2040), **약 2.7배**
- 하단: 출처 푸터 + 페이지 번호

**설계 결정 이력**
1. 처음에는 깔때기 3박스(고령인구 → 인정자 → 재가급여 시장)를 검토했다. 미니 그래프 대신 숫자 증가율로 가기로 했으나, 사용자 초안은 **"수요" 한 축**으로 정리했다.
2. 초안 1차본은 우측이 급여비(2024 16.18조 → 2032 34.7조)였다. 좌측은 인구(사람), 우측은 돈으로 축이 충돌하고 시점도 2045 대 2032로 어긋나 **인정자 2.7배로 교체**했다.
3. 재가급여 시장 규모·증가율은 기대효과 섹션(9번)으로 옮긴다.
4. 리뷰 결과 **수정 필수 항목은 없다.** 선택 사항은 다음과 같다.
   - "3명 중 1명"은 37%이므로 보수적 표현이라 그대로 써도 안전하다.
   - 시점 불일치(2045 대 2040)는 각 라벨에 연도가 박혀 있어 방어된다. 헤드라인을 "20여 년 뒤"로 바꾸면 더 일관된다.
   - 두 도넛 사이에 `22위 → 1위` 화살표를 넣으면 속도 스토리가 커진다.

**강조할 스토리:** "세계에서 가장 빠르게 늙는 나라" — 2019년 52위 → 2025년 22위 → 2045년 1위 전망.

### 3.2 슬라이드 2-② — 방문요양 메커니즘 (설계 완료)

**헤드라인:** "방문요양은 집으로 찾아가는 돌봄 — 비용은 '기록'을 근거로 지급됩니다"

| 단계 | 내용 | 담당 주체 태그 |
|:---:|---|---|
| 1 | 등급 인정: 신청 → 공단 방문조사 → 등급판정위원회 | 수급자·공단 |
| 2 | 센터 계약: 표준장기요양이용계획서(이용할 서비스 종류·횟수 계획서)를 바탕으로 재가센터 선택 | 수급자·센터장 |
| 3 | 방문 돌봄: 집에서 신체·일상생활 지원 | 요양보호사 |
| 4 | **기록 작성: 매 방문 급여제공기록지** | 요양보호사·사회복지사 |
| 5 | **청구·지급: 기록을 근거로 청구·심사, 사후 환수** | 센터 → 공단 |

- 시각 설계: 1~3단계는 연한 블루(일반 제도 설명), **4~5단계는 진한 블루(우리 문제의 핵심)**.
- 하단 바: "공단이 급여비의 약 91% 부담 → 기록이 곧 지급 근거, 기록이 틀리면 환수 대상"

**슬라이드 넣기 전 확인할 것**
1. 방문요양의 구체 서비스 범위와 본인부담률(재가 15%, 감경·면제)은 **원문으로 미검증**이다. 목업에는 세부를 넣지 않고 "신체·일상생활 지원"으로 뭉뚱그렸다.
2. 지금 확보한 환수 판례는 **고의 허위**(출퇴근 태그 조작) 사례다. 사용자 서사 5번은 "고령·디지털 미숙으로 인한 **실수성** 환수"이므로 별개다. 실수성 환수 근거가 없으면 "환수 **위험**"으로 표현 수위를 낮춘다. 후보: 장기요양 부당청구 사례집(2023), 백세시대 보도(기획서 §1.5 C).
3. 5단계가 카드 한 줄의 한계다. 더 늘리면 인쇄 가독성이 떨어진다.

### 3.3 슬라이드 2-③·2-④ (미설계, 계획만)

**2-③ 고령 종사자 병목**
- 인과: 요양보호사 고령화 → 타이핑·온라인 폼 입력 부담 → 메모 누락·지연 → 사회복지사 재작성 부담
- 복선: "말하는 건 자연스럽다" → 해결책(음성 입력)으로 연결
- 사용할 데이터: KDI의 요양보호사 전망(아래 4.6). 평균연령 59.6세는 기획서에서 온 **2차 출처 수치라 1차 출처 재확인 필요**
- 주의: "온라인 적응력 저하"는 **요양보호사(현장 입력자) 중심**으로 한정한다. 사회복지사까지 확장하려면 별도 근거가 필요하다.

**2-④ 결과**
- 기관·종사자: 기록 미비 → 환수
- 수급자: 기록 단절 → 상태 변화 추적 실패 → 돌봄 연속성 저하
- "기록 누락이 사고를 유발한다"는 **직접 인과로 쓰지 않고** 개연성으로 표현한다.

- ⚠️ 검색 중 "재가 10.19조(방문요양 6.82조)"가 2024로 표기된 곳이 있었으나, 공단 통계연보 기준 2024는 9.24조라 **10.19조는 2025 잠정치로 추정**(미확정). 연도를 섞지 않는다.
- ⚠️ 기간: 고령인구는 2020→2025(5년), 인정자·급여비는 2020→2024(4년). 각 지표에 연도를 명시한다.
- 재가기관: 2020년 19,621개소(전체 25,384개소의 77.3%). 기획서의 "1.7만 개소·6.2조·+12%"는 옛 자료라 **폐기**했다.

### 4.5 향후 전망

| 지표 | 전망 | 출처 |
|---|---|---|
| 총지출 | 2023 14.6조 → **2032 34.7조** (연평균 +10.1%, 약 2.4배) | 국회예산정책처 2023~2032 재정전망 |
| 총비용 | 2055년 120.4조(기준) / 89.2조(통합) | 재정전망 보도 |
| 수요 | 2043년 2023 대비 **2.4배** | KDI |

⚠️ NABO의 "10.3→22.4조"는 **보험료 수입**이므로 급여비와 혼동하지 않는다. 34.7조는 총지출이며, 2055년 120.4조의 기준 연도(2024년 14.8조)는 공단 통계 16.18조와 기준이 달라 비교하지 않는다.

**2046년 단일 연도로 통일하는 안은 폐기**했다. 공식 전망은 2040·2045·2055 같은 기준 연도에만 있어 2046은 전부 보간 추정이 되고 "출처?" 반박에 취약하다. "약 20년 뒤 + 공식 기준 연도"로 표기한다.

### 4.6 인력 전망 (2-③용, KDI)

- 요양보호사 추가 필요: 2033년 33.2만 → 2038년 62.5만 → **2043년 99만 명**
- 요양보호사 1인당 수급자: 2023년 1.5~1.9명 → 2040년 **3.0~3.7명**
- 공급: 2023년 71만 명 → 2034년 80.6만 명에서 정점 후 감소. 증가를 60세 이상 고령 인력이 주도하고, 고령화로 실효 인력은 더 줄어든다.
- 2020 통계연보: 요양보호사 450,970명 · 사회복지사 30,268명(전년 +14.7%)

### 4.7 제도·기록 사실 (2-②용)

- 제도 시행: 2008년 (통계연보 발간 기준)
- 이용 절차: 신청 → 공단 방문조사(간호사·사회복지사 등) → 등급판정위원회 → 인정서·표준장기요양이용계획서 → 재가급여 이용
- 기록 의무: 노인장기요양보험법 시행규칙 제18조. 급여제공기록지에 실시내역을 기재하고 수급자에게 제공. **주 1회 이상** 수급자·보호자에게 제공. 방문요양 서식은 별지 제12호
- 기록의 용도: 기관이 공단에 급여비용을 청구할 때의 근거 자료, 청구내역 소명 시 제출
- 환수 사례: 허위 출퇴근 기록(신발장 태그 조작)으로 부풀려 청구한 기관에 대한 **3,740만 원대 환수 처분을 법원이 정당하다고 판단**

## 5. 발표 멘트 후보

수요 증가를 한 방에 전달하는 후보. 전부 출처 있는 수치이며, **톱픽은 ①**이다.

1. **수요 vs 공급 대비 (톱픽):** "돌봄받을 사람은 20년 뒤 2.7배. 그런데 돌볼 사람은 99만 명이 모자랍니다." 숫자 뒤 1초 정지 후 반전.
2. **개인화:** "20년 뒤, 3명 중 1명이 노인입니다. 그 돌봄의 기록은 누가 감당할까요?" (현재 2-① 헤드라인)
3. **속도:** "초고령사회 진입에 프랑스는 39년, 일본은 10년, 한국은 7년." (미검증. 사용 전 확인 필요)
4. **현장 시점:** "요양보호사 1명이 돌보던 1.7명이 20년 뒤엔 최대 3.7명이 됩니다."
5. **브릿지:** "돌봄 수요는 쓰나미처럼 밀려오는데, 그 기록은 아직도 고령의 손끝 하나에 달려 있습니다."

**정직 가드:** 자극적이되 과장·공포 조장은 8인 전문 심사에서 역효과다. 수치 표현을 "최대", "이상", "전망"으로 보수적으로 쓴다.
