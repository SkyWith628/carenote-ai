기술 스택과 안전 원칙

통합기술설계서 §3.2 · §5
영역우선 검토안
FrontendNext.js 반응형 웹 (MediaRecorder 녹음)
BackendFastAPI. 녹음 접수와 작업 상태 조회, 음성인식은 별도 워커
ASRWhisper-small + PEFT LoRA, 배포는 faster-whisper. 비교: large-v3, Qwen3-ASR
사실 추출구조화 출력 LLM. 외부 API는 마스킹 후, 로컬 Qwen3 후보
양식 작성코드 기반 필드 매핑·검증. 문장 다듬기에만 제한적으로 LLM
DB / 검색PostgreSQL (필요 시 pgvector), 작업 큐 Redis
워크플로고정 절차와 명시적 규칙 우선. 분기·중단·재개가 필요할 때만 LangGraph

의도적 비목표 · LangGraph, 파인튜닝, 자율 브라우저 조작은 목표로 삼지 않습니다. 문서 생성 LLM 파인튜닝은 보류하고, 음성인식 경량 학습(LoRA)만 핵심 연구로 둡니다.

  • ✓음성에 없는 관찰·수행 사실을 추가하지 않습니다.
  • ✓애매한 구간은 확정하지 않고 원문과 함께 확인을 요청합니다.
  • ✓원문 전사, 추출 사실, 양식 문장을 따로 보관하고 승인 전후 기록을 구분합니다.
  • ✓음성은 자체 운영 서버에서 처리합니다. 외부 LLM으로 보낼 때는 개인정보를 최소화·가명화합니다.
  • ✓수정·승인 이력은 감사로그로 남기고, 원문 개인정보는 불필요하게 중복 저장하지 않습니다.
  • ✓자동채움은 데모용 자체 양식에서만 검증합니다. 무인 자동 제출은 없습니다.
